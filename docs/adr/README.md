# Architecture Decision Records

Significant technical decisions that are expensive to reverse and important to preserve.

Use the [template](0000-template.md) for new ADRs. Number sequentially. Write in past
tense once the decision is settled. Keep each record self-contained — a reader two years
later should not need to page through git history to understand why.
